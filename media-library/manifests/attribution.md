# Atribuciones y créditos — BAFRAS_Website_Visual_Assets_V1

Fecha de consulta de todas las fuentes: **2026-11-02**. Fuente única de las fotografías: Wikimedia Commons (página de cada archivo verificada mediante la API oficial).

## Cómo aplicar los créditos en la web

- **Atribución obligatoria (CC BY / CC BY-SA)**: el crédito debe ser visible para quien ve la imagen. Lo recomendado es un pie discreto junto a la imagen o una página de «Créditos de imágenes» enlazada desde el pie de página **y** desde cada imagen (por ejemplo, con un icono ⓘ). Debe incluir el título u obra, el autor, la licencia con enlace y la indicación de que se ha modificado.
- **CC BY-SA (ShareAlike)**: la versión recortada y convertida a WebP es una obra derivada y debe ofrecerse con la misma licencia. Esto afecta solo a ese archivo de imagen, no al resto de la web ni a sus textos.
- **Dominio público y CC0**: no exigen atribución. Se recomienda un reconocimiento voluntario en la página de créditos.
- **Gráficos generados (E01, E07, D06)**: son propios y no requieren crédito, pero **no debe eliminarse el sello «datos sintéticos»**.
