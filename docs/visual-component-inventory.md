# Visual Component Inventory

Patterns used after Visual System & Composition Consolidation V1:

## Shared Visual Grammar

- `layout-editorial` - Layout A, editorial intro with system-level visual.
- `layout-evidence` - Layout B, technical text plus evidence or proof.
- `layout-evidence is-reverse` - Layout B with evidence leading.
- `layout-feature` - Layout C, full-width portfolio or proof row.
- `asset-slot[data-content-status="placeholder"]` - pending real evidence.
- `technical-metrics` - sparse attributable metrics.

Reference: `docs/visual-system-v1.md`
